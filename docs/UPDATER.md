# GitHub updater (1.8)

SimpleActivity retains UpdateViewModel through recreation. Checks public GitHub `releases/latest` on entry (no credentials). Successful metadata cached 6 hours; failures back off 15 minutes; dismissed tags stay dismissed. Offline/check failures never block VPN. Downloads start only on tap, have progress/cancel/retry, and cannot run twice concurrently. English/Persian copy uses the existing Vazirmatn font.

Only stable numeric `v?major.minor[.patch]` releases newer than installed versionName qualify. Draft/prerelease metadata is rejected. Exact `SahandVPN_<version>_<ABI>.apk` names in device ABI order, then universal, are accepted. Unsupported ABI uses universal. The existing release ABI outputs all use versionCode 4,010,009; installation compares the real installed longVersionCode, not base Gradle code.

Downloads use a separate TLS-validating OkHttp client, HTTPS-only manual redirects (max 5), trusted GitHub/CDN origins, 15-second connect / 30-second read / 5-minute call timeouts, max 150 MiB, exact metadata/body byte counts, optional GitHub SHA-256. No TLS verification bypass. APKs live in private cache updates/, partial files are deleted on all exits. Before installation check package com.sahand.vpn, release versionName, increasing actual versionCode, minSdk and exact current signing certificate set (API 24-27 GET_SIGNATURES; 28+ GET_SIGNING_CERTIFICATES). Rotated certificates are deliberately rejected unless exactly current signers match.

A dedicated non-exported UpdateFileProvider (distinct from upstream cache provider) grants only read access. Android 8+ requires user approval of 'Allow from this source' (REQUEST_INSTALL_PACKAGES); return from Settings revalidates and opens Android installer. Android confirmation remains mandatory; this is not silent installation. Denial/cancel leaves a manual Install button; recreation does not reopen installer automatically. Process death does not auto-resume an installation/download; next check can offer download again.

## Build prerequisites

Clone recursively (`git submodule update --init --recursive`), install SDK platform 37/build-tools 37.0.0 and NDK 30.0.16248370. Supply `V2rayNG/app/libs/libv2ray.aar` built from AndroidLibXrayLite or its matching upstream release. Build native bridge from repository root with `NDK_HOME="$ANDROID_HOME/ndk/30.0.16248370" bash compile-hevtun.sh`, copy `libs/*` into `V2rayNG/app/libs/`. These native dependencies are not generated by the Android Gradle task. Use your own keystore.properties (never commit it); a new key cannot update installed public builds.

```
export JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home"
export ANDROID_HOME="$HOME/Library/Android/sdk"
cd V2rayNG
./gradlew :app:testPlaystoreDebugUnitTest :app:assemblePlaystoreRelease --console=plain
```

A clean-clone native dependency build has not been independently exercised here. Existing VPN reliability code is unchanged.

# API and functional overview (current 1.10 + future planned for 1.11):
# - Kill-switch system integration via CoreVpnService (https://developer.android.com/guide/topics/connectivity/vpn#vpn_permission)
# - System status: CoreVpnService broadcasts SYSTEM_STATUS intent with alwaysOn and lockdown extras
# - Always-on VPN enforcement: Settings.ACTION_VPN_SETTINGS, never implement an app preference as equivalent OS lockdown
# - Theme persistence: ThemeManager.setThemeMode(mode) loads from SharedPreferences
# - Language selection: AppLocaleManager.setApplicationLanguage(code) recreates activity
# - Diagnostics: Use android.os.StatFs, TrafficStats, WifiManager for counters (planned in 1.11)
# - Endpoint choice: SimpleConfig.Winner.sort by delay, improve endpoint selection from persisted history
# - Resource tuning: bound SimpleConfig.TARGET_WORKING, TCP_CONCURRENCY, SCAN_CHUNK
# - TLS config: UpdateCheckerManager with strict TLS verification
# - Log sanitization: no secrets or endpoints in logs
# - Connection timer: LaunchCore plus TrafficStats.getTotalRxBytes/getTotalTxBytes
